KCE CHATBOT  -  START HERE
==========================

Ithu muzhu project folder. Ellam ulla irukku.


FIRST TIME MATTUM
-----------------
1. Python install aagirukkanum.  (terminal-la:  python --version)
2. Indha folder-kulla terminal open pannunga.
   (File Explorer-la mela address bar-la  powershell  nu type pannitu Enter)
3. Idhai run pannunga:

       pip install -r requirements.txt


ODA VIDA
--------
Easy vazhi:   run_kce.bat  -a double click pannunga.

Illa terminal-la:

       $env:HF_TOKEN="hf_unga_token"
       python app.py

Browser-la:   http://127.0.0.1:5000

HF_TOKEN illama-um velai seiyum. Aana appo AI nalla answer tharaadhu,
database + website-la irundhu neraiya answer mattum varum.
